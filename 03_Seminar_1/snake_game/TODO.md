각 작업을 완료할 때마다 체크하고 완료 내용을 한 줄로 남깁니다.

## 진행 기록

- **1. 작업 계획 정리** — PRD 기준으로 8단계 체크리스트를 만들어 TODO.md에 기록.
- **2. 기본 골격** — `index.html` 생성. 다크 테마 CSS(CSS 변수), 제목 / 점수 표시 /
  400x400 캔버스 / 조작 안내로 구성된 세로 중앙 정렬 레이아웃.
- **3. 상태 및 초기화** — `GRID=20`, `CELL=20`, `SPEED_MS=125` 상수와
  `snake / direction / nextDirection / food / score / state` 상태 정의.
  `resetGame()`은 중앙에서 오른쪽을 향한 길이 3 지렁이로 초기화.
  `spawnFood()`는 빈 칸 후보 목록에서 무작위 선택 → 몸과 겹칠 가능성 원천 차단.
- **4. 게임 로직** — `step()`에서 방향 확정 → 머리 좌표 계산 → 벽 충돌 검사 →
  먹이 판정 → 자기 몸 충돌 검사(먹지 않은 경우 꼬리 칸 제외) → `unshift`/`pop`.
  먹이 섭취 시 점수 +10, 길이 +1, 새 먹이 생성.
- **5. 렌더링** — `draw()`에서 배경 → 격자선 → 먹이(원형) → 지렁이(머리/몸 색 구분) 순으로 그리고,
  일시정지·게임 오버 시 `drawOverlay()`로 반투명 오버레이와 안내 문구 표시.
- **6. 입력 처리** — 방향키와 WASD를 `KEY_TO_DIRECTION`으로 매핑. 정반대 방향 입력은 무시하고,
  입력은 `nextDirection`에 예약해 한 틱 안 이중 회전으로 자멸하는 버그를 방지.
  Space는 플레이 중 일시정지 토글, 게임 오버 시에는 Space/Enter 모두 재시작.
- **7. 메인 루프** — `requestAnimationFrame` + 누적 시간 방식으로 `SPEED_MS`마다 `step()` 호출.
  주사율이 달라도 이동 속도가 일정하며, 일시정지/게임 오버 시 누적값을 초기화.
- **8. 검증** — 브라우저로 `index.html`을 열어 실행 확인 (`Start-Process`).
  체크 항목: 방향 전환, 역주행 무시, 먹이 섭취 시 길이·점수 증가, 벽/자기 몸 충돌 게임 오버,
  일시정지 및 재시작 동작, 콘솔 에러 없음.
